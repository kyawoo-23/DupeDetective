# Documentation layout

- `PRD.md`: product requirements and scope.
- `agents/scan-sources.md`: source intake and identity.
- `agents/component-analysis.md`: deterministic discovery and matching.
- `agents/preview.md`: isolated preview and mock props.
- `agents/review-and-outputs.md`: decisions and generated artifacts.

Keep task-specific agent guidance in `agents/`. The root `AGENTS.md` is the short index.
